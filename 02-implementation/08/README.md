# 8번 - 문자열 재정렬

- 출처: 이것이 취업을 위한 코딩 테스트다 with 파이썬
- 난이도: ●○○
- 풀이 시간: 20분
- 시간 제한: 1초
- 메모리 제한: 128MB
- 알고리즘: 구현
- 기출: Facebook 인터뷰

## 문제 설명
알파벳 대문자와 숫자(0 ~ 9)로만 구성된 문자열이 입력으로 주어집니다. 이때 모든 알파벳을 오름차순으로 정렬하여 이어서 출력한 뒤에, 그 뒤에 모든 숫자를 더한 값을 이어서 출력합니다.

예를 들어 K1KA5CB7이라는 값이 들어오면 ABCKK13을 출력합니다.

## 제약조건
- 첫째 줄에 하나의 문자열 S가 주어집니다. (1 ≤ S의 길이 ≤ 10,000)
- 출력 조건: 첫째 줄에 문제에서 요구하는 정답을 출력합니다.

## 예제

```
입력 예시 1
K1KA5CB7

출력 예시 1
ABCKK13
```

```
입력 예시 2
AJKDLSI412K4JSJ9D

출력 예시 2
ADDIJJJKKLSS20
```

## 문제 요약
알파벳 대문자와 숫자(0~9)로만 구성된 문자열이 주어질 때, 알파벳을 오름차순으로 정렬해서 먼저
출력하고, 그 뒤에 문자열에 있던 모든 숫자의 합을 이어서 출력하는 문제입니다.
