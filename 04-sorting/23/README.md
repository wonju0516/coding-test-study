# 23번 - 국영수

- 출처: 이것이 취업을 위한 코딩 테스트다 with 파이썬
- 난이도: ●○○
- 풀이 시간: 20분
- 시간 제한: 1초
- 메모리 제한: 256MB
- 알고리즘: 정렬
- 기출: 핵심 유형
- 링크: https://www.acmicpc.net/problem/10825

## 문제 설명
도현이네 반 학생 N명의 이름과 국어, 영어, 수학 점수가 주어집니다. 이때, 다음과 같은 조건으로 학생의 성적을 정렬하는 프로그램을 작성하세요.

1. 국어 점수가 감소하는 순서로
2. 국어 점수가 같으면 영어 점수가 증가하는 순서로
3. 국어 점수와 영어 점수가 같으면 수학 점수가 감소하는 순서로
4. 모든 점수가 같으면 이름이 사전 순으로 증가하는 순서로 (단, 아스키코드에서 대문자는 소문자보다 작으므로 사전 순으로 앞에 옵니다.)

## 제약조건
- 첫째 줄에 도현이네 반의 학생 수 N(1 ≤ N ≤ 100,000)이 주어집니다.
- 둘째 줄부터 한 줄에 하나씩 각 학생의 이름, 국어, 영어, 수학 점수가 공백으로 구분해
  주어집니다.
- 점수는 1보다 크거나 같고, 100보다 작거나 같은 자연수입니다.
- 이름은 알파벳 대소문자로 이루어진 문자열이고, 길이는 10자리를 넘지 않습니다.
- 출력 조건: 정렬 기준으로 정렬한 후 첫째 줄부터 N개의 줄에 걸쳐 각 학생의 이름을 출력합니다.

정렬 기준:
1. 국어 점수가 감소하는 순서로
2. 국어 점수가 같으면 영어 점수가 증가하는 순서로
3. 국어 점수와 영어 점수가 같으면 수학 점수가 감소하는 순서로
4. 모든 점수가 같으면 이름이 사전 순으로 증가하는 순서로

## 문제 요약
N명 학생의 이름과 국/영/수 점수가 주어질 때, 국어 점수 내림차순 → 영어 점수 오름차순 → 수학
점수 내림차순 → 이름 사전순의 다중 기준으로 정렬하여 이름만 출력하는 문제입니다.
