# 32번 - 정수 삼각형

- 출처: 이것이 취업을 위한 코딩 테스트다 with 파이썬
- 난이도: ●◐○
- 풀이 시간: 30분
- 시간 제한: 2초
- 메모리 제한: 128MB
- 알고리즘: 다이나믹프로그래밍
- 기출: IOI 1994년도
- 링크: https://www.acmicpc.net/problem/1932

## 문제 설명
위 그림은 크기가 5인 정수 삼각형의 한 모습입니다.

맨 위층 7부터 시작해서 아래에 있는 수 중 하나를 선택하여 아래층으로 내려올 때, 이제까지 선택된 수의 합이 최대가 되는 경로를 구하는 프로그램을 작성하세요. 아래층에 있는 수는 현재 층에서 선택된 수의 대각선 왼쪽 또는 대각선 오른쪽에 있는 것 중에서만 선택할 수 있습니다.

삼각형의 크기는 1 이상 500 이하입니다. 삼각형을 이루고 있는 각 수는 모두 정수이며, 그 값의 범위는 0 이상 9999 이하입니다.

## 제약조건
- 첫째 줄에 삼각형의 크기 n(1 ≤ n ≤ 500)이 주어지고, 둘째 줄부터 n + 1번째 줄까지 정수
  삼각형이 주어집니다.
- 삼각형의 크기는 1 이상 500 이하입니다. 삼각형을 이루고 있는 각 수는 모두 정수이며, 그 값의
  범위는 0 이상 9999 이하입니다.
- 출력 조건: 첫째 줄에 합이 최대가 되는 경로에 있는 수의 합을 출력합니다.

## 예제

```
입력 예시
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5

출력 예시
30
```

## 문제 요약
정수 삼각형의 맨 위층부터 시작해 아래층으로 내려올 때 대각선 왼쪽 또는 오른쪽에 있는 수 중
하나만 선택할 수 있는 상황에서, 선택된 수의 합이 최대가 되는 경로의 합을 구하는 문제입니다.
