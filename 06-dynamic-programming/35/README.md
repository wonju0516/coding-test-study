# 35번 - 못생긴 수

- 출처: 이것이 취업을 위한 코딩 테스트다 with 파이썬
- 난이도: ●◐○
- 풀이 시간: 30분
- 시간 제한: 1초
- 메모리 제한: 128MB
- 알고리즘: 다이나믹프로그래밍
- 기출: Google 인터뷰

## 문제 설명
못생긴 수란 오직 2, 3, 5만을 소인수Prime Factor로 가지는 수를 의미합니다. 다시 말해 오직 2, 3, 5를 약수로 가지는 합성수를 의미합니다. 1은 못생긴 수라고 가정합니다. 따라서 못생긴 수들은 {1, 2, 3, 4, 5, 6, 8, 9, 10, 12, 15, ...} 순으로 이어지게 됩니다. 이때, n번째 못생긴 수를 찾는 프로그램을 작성하세요. 예를 들어 11번째 못생긴 수는 15입니다.

## 제약조건
- 첫째 줄에 n이 입력됩니다. (1 ≤ n ≤ 1,000)
- 출력 조건: n번째 못생긴 수를 출력합니다.

## 예제

```
입력 예시 1
10

출력 예시 1
12
```

```
입력 예시 2
4

출력 예시 2
4
```

## 문제 요약
오직 2, 3, 5만을 소인수로 가지는 수(1도 못생긴 수로 간주)를 순서대로 나열했을 때, n번째
못생긴 수를 구하는 문제입니다.
